# NCUT Network Traffic

北方工业大学校园网流量余量 macOS 菜单栏小工具。

> **声明：个人非官方作品，与北方工业大学及学校网络中心无关。**
> 仅供学习交流，使用本工具产生的一切后果由使用者自行承担。

## 它做什么

- 常驻 macOS 右上角菜单栏，显示校园网剩余流量（如 `59.0G`）
- 点击下拉查看已用流量、套餐、在线设备数、上次更新时间
- 连上校园网（`NCUT` / `NCUT-AUTO`）时自动查询，其余时间显示离线

## 隐私与安全（给较真的人看的）

- **只读查询**：只调校园网自助 portal 的 `rad_user_info` 只读接口，不登录、不绕过任何认证。未登录就显示"未登录"，请去浏览器完成认证
- **不碰密码**：代码里没有任何密码框、没有任何凭证存储，也永远不会加自动登录功能
- **数据不出本机**：查询结果只在内存里展示，学号显示时脱敏（如 `2026***0050`），不上传到任何地方
- **请求频率**：每 5 分钟查一次 + 唤醒/手动刷新，对服务器负载可忽略，约等于多刷了一次浏览器页面

## 构建

1. 用 Xcode 打开 `NCUT Network Traffic.xcodeproj`
2. 在 Signing & Capabilities 里选**你自己的** Team（仓库里不含任何签名身份）
3. Run 即可，仅支持 macOS（`MenuBarExtra` 需要 macOS 13+）
